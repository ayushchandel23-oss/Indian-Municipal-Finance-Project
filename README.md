# Indian Municipal Finance Dashboard (Power BI)

## 📊 Project Overview

This project presents an interactive Power BI dashboard analyzing municipal financial performance across major Indian cities from (2012–2018).
The dashboard provides insights into **revenue trends, expenditure patterns, budget balance, and fiscal health of cities using interactive visuals and KPIs.

The goal of this project is to demonstrate data analysis, dashboard design, and storytelling using Power BI.


## 🛠 Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization


## 📁 Dataset

The dataset contains financial information for multiple Indian cities including:

* City
* Fiscal Year
* Total Revenue
* Total Expenditure
* Budget Balance
* Revenue Growth %
* Expenditure Growth %

The data covers the period (2012–2018).


## 📌 Dashboard Pages

### 1️⃣ Overview

* Total Revenue and Total Expenditure KPIs
* Budget Balance trends
* Revenue vs Expenditure comparison
* Growth percentage analysis

### 2️⃣ Revenue Analysis

* Revenue growth trends by fiscal year
* Top cities by revenue
* Identification of highest revenue year
* Revenue trend visualization

### 3️⃣ Expenditure Analysis

* Expenditure growth trends
* Top cities with highest spending
* Total expenditure trends over time

### 4️⃣ Fiscal Health & Performance

* Budget balance trends
* Surplus vs Deficit city distribution
* Financial health categorization
* City-level fiscal performance matrix


## 📈 Key Insights

* Municipal revenues steadily increased between 2012 and 2018.
* Some cities consistently generated **higher revenues and expenditures.
* Budget balance trends reveal years with deficits and fiscal improvements.
* Fiscal health categorization helps identify financially strong vs struggling cities.
